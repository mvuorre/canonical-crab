## Reproduce

All the code is [R](https://cran.r-project.org/) and written as [Quarto](https://quarto.org/) documents. To reproduce, restore the environment with renv, then run index.qmd. Or just use [GNU Make](https://www.gnu.org/software/make/):

```bash
make
```
